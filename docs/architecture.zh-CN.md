# NumPatch 运行结构

[English](architecture.md) · [简体中文](architecture.zh-CN.md)

## 输入通路

1. 数字模式开启或校准时才启动设备及事件 tap。原始触点由 MultitouchSupport 回调推送；最多保留两个有效触点，即可完成“单指/多指”判断，无需采样轮询或触点显示队列。
2. 触点与鼠标回调共享带锁的 TakeoverEngine。界面线程不参与输入判定。只有在数字模式开启时运行轻触识别，校准时仅更新当前触点状态。
3. 主动 tap 位于 session 入口，仅订阅左键 down/up/drag。右键及其他鼠标键通过独立 listenOnly tap 取消待输出数字候选，不修改或拦截其系统行为。
4. 同一触点序列必须短时、低位移、单指且没有物理按下。候选跟踪其前台 PID；切换应用、改变布局、新接触或鼠标按下都会取消旧候选。
5. 系统轻触点击先到则成对过滤 down/up。没有系统点击的有效候选约 30 ms 后从原始触点补发；候选只消费一次，迟到的相关点击和配对释放不会重复输出。
6. 键盘事件源在 tap 安装前创建，localEventsSuppressionInterval 为 0。确定需要输出后才复制键盘事件，在独立串行队列通过目标 PID 发送小键盘 down/up；保留修饰键及 numericPad 标志。
7. 关闭数字模式后停止触点回调并卸载所有 tap。若已有吞掉的 down，短暂等待配对 up 后停止。睡眠时暂停；重新开启时再次校验设备与权限。

## 日常运行与界面

没有逐帧原始触点 UI、压力/面积显示、帧计数、逐次输入日志、文件写入或常驻刷新计时器。主窗口可见且数字模式开启时，每次有效输出向独立预览模型投递一次按键及位置；程序自身窗口内的有效轻触仅用于练习，不注入按键。关闭、最小化、完全遮挡或打开设置/校准页后移除反馈回调，代次检查丢弃已排队的旧更新。其余窗口只在设置、权限、模式或校准进度变化时更新。参数持久化及识别器配置只发生于设置变化。`--diagnostics` 为开发用途，默认关闭。

暂停状态的“已校准”仅为当前开机缓存提示；每次真正开启仍会核对设备 ID、开机 UUID、样本有效性和主动过滤能力，缓存提示不能授权发键。

## 布局与几何

未分配边角不参与自定义区域命中，直接使用九键数字。启用的四角优先于边条，采用四分之一圆。四边使用贴边中间线段的距离构成半胶囊轮廓，贴边直角、朝内圆弧。每条边独立保存长度（该边 4%–80%）及深度（短边 1%–24%，不超过长度一半）；缩短可变为小半圆。识别与静态预览使用一致的 1.5:1 几何，测试覆盖四个方向和不同长度的预览/命中一致性。

## 校准与边界

校准向导只采集蓝色区域内的事件，忽略重复编号；轻触和按压各三次。签名为 subtype、量化 pressure 以及事件到达时触点是否已离开的组合；两组必须不重叠。不把 touch subtype 或压力本身视作通用的轻触判据。

使用私有 MultitouchSupport ABI，兼容性依赖系统和设备。样本可区分与自动化测试均不能证明所有触控板、轻触拖移、外接鼠标及目标应用都兼容。发布前仍需实机验证。当前本机构建为 Apple Development 签名版本，未做 Developer ID 分发签名和公证。

## 语言与设置兼容

英文与简体中文通过 SwiftPM 资源包加载。语言偏好默认英文；状态消息保留翻译键及插值，切换后立即重绘。显示名称不参与键码映射，旧的布局标识、bundle identifier 和偏好设置键保持稳定。改变语言不会重新配置输入引擎。

## 菜单栏与快捷键

通过 LSUIElement 和 accessory 激活策略隐藏 Dock、应用切换器入口。单个保留的 AppKit 窗口承载 SwiftUI，⌘W 与关闭按钮收起窗口，数字模式继续工作；菜单栏重用该窗口。窗口可见性、遮挡和 sheet 通知控制实时反馈。

快捷键按虚拟键码、Carbon 修饰键及显示名称存储。录制只使用本地第一响应者，期间暂停旧快捷键；Esc、焦点离开、关闭窗口或移除控件均结束录制。正常替换先注册新组合再释放旧组合，录制失败恢复旧组合，不使用全局键盘事件监听。
