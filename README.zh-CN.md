# NumPatch

**为 Mac 补上数字小键盘。**

[English](README.md) · [简体中文](README.zh-CN.md)

NumPatch 将 Mac 触控板变成可自定义的数字小键盘。轻触不同区域即可发送真正的小键盘按键，让没有实体数字小键盘的 MacBook 也能使用依赖小键盘键码的快捷键。

适用于 Blender 等支持小键盘快捷键的软件，可用于切换视图、聚焦选中对象，以及触发用户自定义的小键盘操作。

## 功能

- **3×3 数字布局。** 大面积区域对应数字 1–9；默认在触控板下边缘设置 `0` 和 `.`。
- **可自定义按键。** 在四角和四边添加按键，并调整区域大小。支持 `0–9`、`.`、`/`、`*`、`−`、`+`、小键盘回车、退格、Tab、Esc 和空格。
- **发送小键盘键码。** 应用可识别独立数字小键盘按键，实体键盘上的 Control、Shift、Option、Command 修饰键也可组合使用。
- **按需启用。** 使用全局快捷键切换数字模式；暂停后恢复触控板轻触操作。双指辅助点按继续执行系统右键操作。
- **菜单栏运行。** 关闭主窗口后，NumPatch 保留在菜单栏并继续运行；从菜单栏可重新打开窗口或退出应用。
- **快捷键可配置。** 默认快捷键为 **⌃⌥⌘N**，可在“设置 → 识别 → 通用”中录制新的组合键或功能键。
- **布局反馈。** 主窗口显示按键布局、最近触发的按键和对应触控位置。
- **中英文界面。** 默认使用英文，可在“设置 → 识别 → 通用 → 语言”切换为简体中文。

默认布局：

```text
┌─────────┬─────────┬─────────┐
│    7    │    8    │    9    │
├─────────┼─────────┼─────────┤
│    4    │    5    │    6    │
├─────────┼─────────┼─────────┤
│    1    │    2    │    3    │
└─────────┴──[ 0 ]──┴─────[.]─┘
```

## 使用方法

1. 打开 NumPatch，并在 macOS 提示时授予辅助功能权限。
2. 在“系统设置 → 触控板”中启用“轻点来点按”。
3. 按照校准向导完成触控板校准。
4. 启用数字模式，轻触对应区域，将按键发送到当前使用的应用。
5. 使用全局快捷键暂停数字模式，返回常规触控板操作。

在“编辑布局…”中设置边角按键和区域大小。选择“录制快捷键…”可修改数字模式的全局快捷键。设置会自动保存。

## 构建

NumPatch 需要 macOS 13 或更新版本，以及 Swift 5.9 或更新版本。

```sh
swift test --disable-sandbox
./scripts/build.sh
open dist/NumPatch.app
```

构建应用需要可用的本机代码签名身份。

## 开发

界面使用 SwiftUI 和 AppKit，触控板事件由 C 桥接接收。更多实现说明见[架构文档](docs/architecture.zh-CN.md)。
