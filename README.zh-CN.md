# NumPatch

**Give your Mac a numpad. 为你的 Mac 补上数字小键盘。**

[English](README.md) · [简体中文](README.zh-CN.md)

将 Mac 触控板变成 3×3 数字小键盘，并在四角、四边添加可自定义的按键。需要输入数字或使用小键盘快捷键时开启，结束后暂停，回到平常的触控板操作。

适合使用 MacBook 或紧凑键盘的人：Blender 视图操作、建模中的精确数值输入、表格录入，以及经常使用小键盘快捷键的软件。

> 当前为早期开发预览版。构建目标为 macOS 13 及以上，设备与应用兼容性仍在测试中。目前尚未提供可下载的正式安装包。

## 功能

- **发送真正的小键盘事件。** 使用 macOS 小键盘键码和 numeric-pad 标志，支持搭配实体键盘上的 Control、Shift、Option、Command。
- **纯九键布局。** 1–9 使用较大的识别区域；默认下边中间为 `0`，右下角为 `.`。
- **八个可选的边角键。** 四角、四边独立分配；边条可拉长，也可缩成小半圆，角落大小可调。未分配的区域仍按原来的 1–9 范围识别。
- **保留系统轻触。** 无需关闭 macOS 的“轻点来点按”。数字模式接管识别到的单指轻触，双指辅助点按继续由系统处理。
- **快捷切换。** 使用 **Control + Option + Command + N**、菜单栏或主窗口开关。正常启动默认暂停，睡眠时自动暂停。
- **中英双语。** 默认英文，不随系统语言改变；在 **Settings → Recognition → General → Language** 选择“简体中文”，立即生效并保存。中文路径为“设置 → 识别 → 通用 → 语言”。
- **暂停后停止触控采样。** 卸载鼠标事件监听、停止触控板回调；开启时接收驱动推送，不依赖持续刷新界面的计时器。

```text
┌─────────┬─────────┬─────────┐
│    7    │    8    │    9    │
├─────────┼─────────┼─────────┤
│    4    │    5    │    6    │
├─────────┼─────────┼─────────┤
│    1    │    2    │    3    │
└─────────┴──[ 0 ]──┴─────[.]─┘
                 默认布局示意
```

可分配 `0–9`、`.`、`/`、`*`、`−`、`+`、小键盘回车、退格、Tab、Esc 和空格。角落使用四分之一圆，边条贴边部分为直角、向内部分为圆角。

## 使用场景

下列场景依据各软件的官方文档整理，**并非已完成实机验证的兼容软件清单**。使用时请结合软件版本和快捷键配置测试。

| 软件 | 场景 |
| --- | --- |
| **Blender** | 使用小键盘快捷键切换建模视图，或分配 `.` 聚焦选中对象。Blender 区分小键盘与键盘上排数字。参见[视图快捷键](https://docs.blender.org/manual/en/latest/editors/3dview/navigate/viewpoint.html)及[聚焦选中对象](https://docs.blender.org/manual/en/latest/editors/3dview/navigate/navigation.html#frame-selected)。 |
| **Rhino** | 精确建模时输入距离、尺寸等数值；坐标和角度表达式中的其他符号可搭配实体键盘输入。参见[精确建模](https://docs.mcneel.com/rhino/mac/help/en-us/user_interface/accurate_modeling.htm)。 |
| **SketchUp** | 在测量框输入精确尺寸或缩放数值。参见[使用测量值缩放模型](https://help.sketchup.com/en/sketchup/scaling-your-model-or-parts-your-model)。 |
| **Apple Numbers** | 使用紧凑键盘时，录入数量、价格等表格数值。参见[输入文字和数字](https://support.apple.com/guide/numbers/tanbc336eea7/mac)。 |

Rhino、SketchUp、Numbers 展示的是数字输入场景，并不要求使用独立小键盘键码。其他允许自定义小键盘快捷键的 CAD、三维、音频或剪辑软件也可尝试。NumPatch 暂无专门的应用插件或官方合作关系。

## 开始使用

目前请按下方步骤从源码构建。

1. 打开 `dist/NumPatch.app`，按提示授予**辅助功能**权限；若系统另外请求发送输入事件的权限，也需允许。
2. 保持**系统设置 → 触控板 → 轻点来点按**开启。需要双指右键时，同时开启系统的双指辅助点按。
3. 完成校准：指针移入蓝色区域、等待一秒，再不按下地单指轻触三次；第二步物理按压三次。
4. 抬起手指后开启数字模式，轻触对应区域，将按键发送到当前前台应用。
5. 需要普通轻触鼠标操作时，按 **⌃⌥⌘N** 暂停。关闭窗口后仍可使用菜单栏，选择“退出 NumPatch”才会退出程序。

在“编辑布局…”中分配边角按键及调整大小，修改自动保存。校准缓存限定当前设备和开机周期；重启系统或更换触控板后可能需要重新校准。

## 构建与测试

需要 macOS、包含 Swift 5.9 及以上版本的 Xcode 命令行工具和可用触控板。构建 `.app` 还需要本机稳定的代码签名身份，无外部 Swift 包依赖。

```sh
# 编译并运行自动化测试，无需签名身份。
swift test --disable-sandbox

# 构建本机签名的应用，不生成 DMG。
./scripts/build.sh
open dist/NumPatch.app
```

脚本默认选择已有的 **Apple Development** 身份，也可设置 `NUMPATCH_SIGN_IDENTITY`。不要提交签名凭据。没有签名身份时，仍可编译和测试，但应用构建脚本会在签名阶段停止。

包、可执行文件及应用均命名为 **NumPatch**。为保留开发期间的设置和签名身份，bundle identifier 仍为 `local.touchpad-keyboard.monitor`。替换旧版后，macOS 仍可能要求重新确认权限。

本轮暂不制作 DMG，待其他发布准备完成后再处理。`scripts/package.sh` 保留为后续打包入口。本机开发签名不等于 Developer ID 分发签名或 Apple 公证。

## 当前限制

- 使用 macOS 私有 `MultitouchSupport` 接口，系统升级或设备差异可能影响行为。目前使用默认触控板，暂无设备选择器。
- 每次有效轻触发送一次短暂的按下/抬起，不支持持续按住虚拟按键及自动连发。
- 物理按压保留鼠标操作；数字模式改变单指轻触的行为，可用快捷键随时切换。
- 暂不承诺所有建模软件、远程桌面、游戏、输入法及受保护输入框都兼容；实际行为受前台应用和快捷键配置影响。
- 日常输入不写入触点/按键日志，也不向服务器发送数据。布局、语言及校准仅保存于本机偏好设置。开发参数 `--diagnostics` 可开启少量 macOS 统一日志。
